ROUTAGE DES NOTES
dernière activité : —

PADS : les notes jouent les 16 pads (note 36 = pad 1, mapping batterie) avec la vélocité, et s'enregistrent dans la grille si ● REC est actif. BASS / WAVE : le clavier joue le synthé choisi (note 24 = C1), et les notes s'écrivent dans le piano roll pendant l'enregistrement. CC74 pilote le cutoff des synthés, CC1 (molette) le filtre du mix.
